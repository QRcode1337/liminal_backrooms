# J-SPACE: explainer video

A roughly 4-minute narrated explainer on **J-space**, Anthropic's name for the small set of
*verbalizable* representations inside a language model. They are found with the
**Jacobian lens** and behave like a global workspace. The video uses the same phosphor-green
CRT look as the liminal_backrooms GUI.

Source: Gurnee, Sofroniew, Lindsey et al., *Verbalizable Representations Form a Global
Workspace in Language Models* (Anthropic, 2026), [arXiv:2607.15495](https://arxiv.org/abs/2607.15495).

## Chapters

| # | Scene | Covers |
|---|-------|--------|
| 00 | Cold open | Title |
| 01 | The question | Silent computation vs. reportable content; global workspace theory |
| 02 | Jacobian lens | `J_ℓ = E[∂h_final,t' / ∂h_ℓ,t]`, `lens(h) = softmax(W_U · norm(J_ℓ h))` |
| 03 | Defining J-space | Sparse non-negative mix of about 25 J-lens vectors; under 10% of variance |
| 04 | Hidden step | "Legs on the animal that spins webs": *spider* appears silently; a swap changes the answer |
| 05 | Five marks | Report, directed modulation, internal reasoning, flexible generalization, selectivity |
| 06 | Selectivity | Ablation breaks flexible reasoning but not automatic skills |
| 07 | Structure | Workspace band (about ⅓ to 9⁄10 of depth), ignition, capacity, broadcast heads |
| 08 | Auditing | Blackmail scenario, eval awareness, reward-hacking model organism |
| 09 | Post-training | Assistant point of view, "BUT", counterfactual reflection training |
| 10 | Limits | Functional analogy only; single-token concepts; bag of features |

Two visuals are illustrative and labelled as such on screen: the spider→ant swap target and the
behaviour bar heights in scene 09.

## Build

```bash
cd jspace_video
npm install

# 1. Voiceover (Kokoro TTS, voice bm_george). Model files:
#    https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
pip install kokoro-onnx soundfile numpy
python3 scripts/tts.py path/to/kokoro-v1.0.int8.onnx path/to/voices-v1.0.bin

# 2. Generated audio beds (not committed)
python3 scripts/drone.py   # ambient drone for the long cuts
python3 scripts/sfx.py     # 100 BPM beat + impact/whoosh/glitch/riser/tick SFX for the short

# Short cut voiceover (script: scripts/short_narration.json)
python3 scripts/tts.py path/to/kokoro-v1.0.int8.onnx path/to/voices-v1.0.bin short 1.0

# 3. Preview / render
npm run studio
npm run render            # -> out/jspace.mp4          (1920x1080)
npm run render:vertical   # -> out/jspace_vertical.mp4 (1080x1920, full 4 min)
npm run render:short      # -> out/jspace_short.mp4    (1080x1920, ~74 s native vertical)
```

In a headless container without Remotion's own browser download, point it at an existing
headless Chromium:

```bash
REMOTION_BROWSER=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell npm run render
```

## Layout

- `scripts/narration.json`: the script, one entry per scene. Edit it, then re-run `tts.py`.
- `src/vo-durations.json`: generated by `tts.py`; scene lengths follow the narration.
- `src/cue.tsx`: `useCue()('phrase')` estimates the frame when a phrase is spoken, so
  animations stay in sync after script edits.
- `src/Video.tsx`: both compositions. `JSpaceVertical` scales the 16:9 scenes into a middle
  band, with a chapter header above and 6-word caption chunks below, kept clear of TikTok's UI
  (top ~150px, bottom ~400px, right ~140px).
- `src/short/`: the ~74 s native-vertical cut (`JSpaceShort`): hook → lens → spider → tiny
  workspace → safety → J-SPACE slam. `fx.tsx` has the effects (perspective corridor, chromatic
  glitch text, slams, camera shake, flashes, glitch cuts, word bursts, kinetic word captions);
  `Scenes.tsx` places each effect and SFX on the narration cue words.
- `src/scenes/*`: one component per scene. `src/ui.tsx` holds the palette, CRT overlay and captions.
